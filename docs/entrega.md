# Evidencias de la práctica

La entrega deberá contener evidencia suficiente para demostrar que el pipeline fue construido y probado.

## Evidencias mínimas

1. Estructura del repositorio y entorno de Codespaces.
2. DAG visible en Airflow.
3. Reporte de profiling.
4. Expectation Suite configurada.
5. Checkpoint configurado.
6. Ejecución con el lote válido.
7. Ejecución con el lote defectuoso.
8. Resultado de los datos publicados en GOLD.
9. Resultado de los datos conservados en QUARANTINE.
10. Respuestas de la sección de reflexión.

## Criterio de evidencia

Las capturas deberán mostrar el contexto necesario para interpretar el resultado. Una captura aislada de un fragmento de código no constituye evidencia suficiente de que el pipeline completo funcione.

## Organización sugerida

La evidencia puede mantenerse dentro de una carpeta local de trabajo o en el documento de entrega. No se deberán versionar archivos generados de gran tamaño dentro del repositorio salvo que se indique expresamente.
